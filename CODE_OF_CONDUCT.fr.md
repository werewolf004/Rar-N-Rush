# Code de conduite

[English](CODE_OF_CONDUCT.md) · **Français**

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En bref : sois respectueux et accueillant, donne et accepte des critiques constructives, et privilégie ce qui est le mieux pour le projet et ses utilisateurs. Le harcèlement, les insultes et les attaques personnelles ne sont pas tolérés.

Signale un comportement inacceptable en privé au mainteneur via GitHub (**Security → Report a vulnerability** peut aussi servir aux signalements confidentiels). Les signalements sont traités de façon confidentielle.
